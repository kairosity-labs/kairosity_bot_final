# FastAPI Server Walkthrough

I have created a FastAPI server `fastapi_server.py` that allows you to run forecasts via a REST API.

## Server Implementation

The server is implemented in [fastapi_server.py](file:///home/ubuntu/kairosity_bot_final/fastapi_server.py). It initializes the `AGForecastBot` and exposes a `/forecast` endpoint.

## How to Run

1.  **Activate Environment:**
    ```bash
    source .venv/bin/activate
    ```

2.  **Start Server:**
    ```bash
    uvicorn fastapi_server:app --port 8000
    ```

## Usage

Send a POST request to `http://localhost:8000/forecast` with the question details.

### Example Request

```bash
curl -X POST "http://localhost:8000/forecast" \
     -H "Content-Type: application/json" \
     -d '{
           "question_text": "What will the Fed decision in January 2026 be?",
           "resolution_criteria": "Resolves to exactly one of the outcomes...",
           "background_info": "The Federal Open Market Committee (FOMC) sets U.S. monetary policy..."
         }'
```

### Response Format

The server returns a JSON object containing:
-   `prediction`: The forecasted value (probability, distribution, or options).
-   `report`: The full markdown report generated by the bot.
-   `classification`: The detected question type and extracted metadata.

```json
{
  "prediction": ...,
  "report": "...",
  "classification": {
    "classification": "multiple_choice",
    "options": [...]
  }
}
```

## Verification

The server was verified by checking the logs during a test run. The bot successfully:
1.  Classified the question.

3.  Proceeded to forecasting.

## Graceful Shutdown

The server implements a graceful shutdown mechanism. When a shutdown signal is received (e.g., `Ctrl+C`), the server will:
1.  Identify all actively running forecast tasks.
2.  Cancel them to prevent zombie processes.
3.  Await their cleanup before terminating.
